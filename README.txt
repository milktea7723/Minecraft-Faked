感谢您游玩这个半成品游戏，以下是游玩方法：
点击Minecraft.exe即可游玩，如果开始游戏白屏，请耐心等待加载。
由于游戏目前处于内测阶段，所以会出现许多bug或闪退情况，如果出现闪退，请将该目录下的log.txt和
崩溃前做了什么私信我，让我们一起将这个游戏变得更加完善！

该游戏版本: alpha 0.1.1

键位：
WASD移动
1~9物品栏快捷键：
1：草方块
2：泥土
3：原石
4：基岩
5：玻璃
6：平滑石
7：钻石块
8：金块
9：木板

T 指令栏(可以输入help来获取指令帮助）
移动鼠标控制摄像机
鼠标左键挖方块
鼠标右键放方块

温馨提示：
在游玩该游戏时，请关掉不必要的软件来预留足够的内存（大概是该电脑的内存的40%左右）给该游戏，
因为游戏会在运行是占用(600mb~至少5gb)较多的内存，但是是随着您的探索（地图的加载量）变化的，
所以如果您的电脑配置较低(<=8gb的内存）请不要太多地探索！！！

Minecraft\options.txt文件夹内中，可调整MAPSIZE大小（边长），请注意不要调太高！！！！！

请勿触动任何源代码（除非你会）
